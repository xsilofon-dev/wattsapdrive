# WattSapDrive на Termux (Android)

Один акаунт WhatsApp → кілька пристроїв (ПК + телефон).  
На телефоні **не використовуй QR** — тільки **код привʼязки**.

## Швидкий старт

```bash
pkg update -y
pkg install -y git nodejs
git clone https://github.com/xsilofon-dev/wattsapdrive.git
cd wattsapdrive
bash install-termux.sh
```

Зі своєю назвою сховища:

```bash
VAULT_NAME="Мій Телефон Диск" bash install-termux.sh
```

Інсталятор:

1. поставить залежності (`npm install`)
2. спитає / запише назву сховища
3. створить `app-config.json` (токен) і порожній каталог
4. запустить бота через `nohup` (без systemd)
5. відкриє `/pair` у браузері (якщо є `termux-open-url`)

## Привʼязка WhatsApp

Відкрий: **http://127.0.0.1:3000/pair**

1. Введи номер з кодом країни (`380XXXXXXXXX`)
2. **Отримати код**
3. WhatsApp → **Повʼязані пристрої → Привʼязати пристрій**
4. **Привʼязати за номером телефону** → введи код

> Тап по QR на тому ж телефоні **нічого не відкриє**. Ігноруй QR.

## Група-сховище

Після логіну в UI зʼявиться блок:

- **обери існуючу групу**, або
- **створи нову** з назвою сховища

Без групи файли не будуть у спільному чаті.

## Той самий акаунт, ПК + Termux

| Що | Як |
|----|----|
| Сесія | На кожному пристрої **окремий** `/pair`. Не копіюй `auth/` |
| Файли | Спільна **одна й та сама група** |
| Дерево папок | На ПК: **↧ Каталог** → перенеси JSON → на Termux: **↥ Імпорт** |

Не запускай два боти з **скопійованою** `auth/` — буде конфлікт **440**.

## Керування

```bash
./start-termux.sh          # старт
tail -f logs/bot.out       # логи
kill "$(cat tmp/bot.pid)"  # стоп
git pull && bash install-termux.sh   # оновлення
```

Оновити лише код без переустановки:

```bash
cd ~/wattsapdrive
git pull
kill "$(cat tmp/bot.pid)" 2>/dev/null || true
./start-termux.sh
```

## Типові проблеми

| Симптом | Що робити |
|---------|-----------|
| QR не клікається | Це нормально. Використовуй **/pair** і код |
| online, але порожньо | Обери/створи групу в UI |
| 440 / постійні reconnect | Закрий WhatsApp Desktop / інший linked-дубль з тією ж `auth/` |
| Не відкривається UI | `curl http://127.0.0.1:3000/api/status` · дивись `logs/bot.out` |
